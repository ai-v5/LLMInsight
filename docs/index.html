01 / FOLLOW THE EVIDENCE
01 / INPUT

接入已有采集

读取 ASCEND_PROFILER_OUTPUT 或 MindStudio msprof-export 目录，也支持每个 rank 独立采集的多 rank 根目录。

02 / ANALYZE

串起指标与归因

从时间线、算子和通信出发，结合模型结构归因与规则诊断，缩小下一步排查范围。

03 / SHARE

带着依据讨论

导出自包含 HTML 报告，把指标与分析带给同事；使用 What-if 推演时，保留假设与实测之间的边界。

LESS GUESSWORK, MORE CONTEXT

性能分析，
不只盯着一个数字。

当前重点支持 DeepSeek-V3 结构的 MoE 训练 Profiling。每项指标都需要结合实际采集内容理解。

查看设计与数据契约 ↗
A

算力、带宽与优化余量

MFU、MBU、Roofline 与理论分析，结合覆盖率和芯片参考值理解效率，避免把估算当作测量。

B

通信、慢卡与集群概览

查看通信分解、重叠和多 rank step 分布，定位离群 rank，并按节点汇总观察。

C

模型语义与隐藏开销

将算子、通信归因到模型结构，结合时间线、显存与隐藏开销，寻找可以继续验证的线索。

D

本地规则，可选 LLM 洞察

默认使用本地规则引擎。LLM 网络调用需显式开启，先确认结构化摘要与模型服务的数据使用边界。

用自己的一份采集开始

02 / GET STARTED
LOCAL FIRST

安装依赖，启动，
选择 Profiling 目录。

准备 Python 3.9+、pip 与 Git。在 PowerShell 中按命令启动，再打开 http://127.0.0.1:8765/。

服务绑定本机回环地址。Linux / macOS 也可使用相同的 Python 启动命令；详细用法见仓库说明。

完整启动与配置说明 ↗
POWERSHELL从源码运行
git clone https://github.com/ai-v5/LLMInsight.git
Set-Location LLMInsight
python -m pip install -r requirements.txt
python -m llminsight.server --port 8765 --no-browser
浏览器打开 127.0.0.1:8765 → 选择采集目录

带着边界理解结果

这个网站用于介绍项目，分析在本机运行。指标是否可用取决于采集文件和算子覆盖；MFU / MBU / Roofline 使用芯片参考峰值，What-if 是假设推演。多 rank 概览与代表 rank 分析不能替代完整的分布式因果诊断。阅读项目说明 →
